# fitness.flow.energy — simplified GitHub Pages website

This version uses Gumroad for all purchases and YouTube for all listening. There are no hosted MP3 previews and no per-track Gumroad URLs.

## Publish
Upload the CONTENTS of this folder to the ROOT of your existing GitHub repository, replacing `index.html`, `style.css`, and `script.js`. Keep the `assets` folder at root. GitHub Pages should remain configured for the `main` branch and `/(root)`.

Your live URLs are already configured:
- Shop: https://flowfit7.gumroad.com/
- YouTube: https://www.youtube.com/@fitness_flow_energy

All six track buttons currently go to the YouTube CHANNEL, not individual videos, because individual video URLs were not supplied. To link each video directly, change its `youtubeUrl` in `script.js`.

The old `assets/previews` folder is no longer needed; you may delete it from GitHub. The existing cover art is retained.

This bundle is based on the original website package, not on any changes you may have made directly in GitHub since. If you have customized your live website, back it up or compare changes before replacing files.
